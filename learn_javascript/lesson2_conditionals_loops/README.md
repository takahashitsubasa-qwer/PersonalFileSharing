# 💡 Lesson 2: 条件分岐とループ

プログラムの「頭脳」とも言える、**状況に応じて処理を変える（条件分岐）**仕組みと、**同じ処理を自動で繰り返す（ループ）**仕組みについて学びます。

---

## 1. 条件分岐（`if`, `else if`, `else`）

特定の条件が成り立つときだけ、特定のコードを実行します。

```javascript
const score = 85;

if (score >= 90) {
  console.log("優秀です！");
} else if (score >= 70) {
  console.log("合格です！");
} else {
  console.log("不合格です。次回頑張りましょう！");
}
```

---

## 2. 比較演算子（値を比べる記号）

JSでは値を比較するために以下の記号（演算子）を使います。

| 演算子 | 意味 | 例 |
| :--- | :--- | :--- |
| `a === b` | a と b は**等しい**（型も同じ） | `5 === 5` (true), `5 === "5"` (false) |
| `a !== b` | a と b は**等しくない** | `5 !== 3` (true) |
| `a > b` | a は b より**大きい** | `10 > 5` (true) |
| `a >= b` | a は b **以上** | `5 >= 5` (true) |
| `a < b` | a は b より**小さい** | `3 < 5` (true) |
| `a <= b` | a は b **以下** | `3 <= 5` (true) |

> ⚠️ **超重要：`===`（厳密等価）を必ず使おう！**
> JSには `=` が2つの `==`（等価）もありますが、これは「型が違っても適当に同じとみなす」という曖昧なルールを持つため、思わぬバグを生みます。
> 例：`5 == "5"` は `true` になってしまいます！
> 安全にプログラミングするため、常に **`===`** を使いましょう。

---

## 3. 論理演算子（条件を組み合わせる）

複数の条件を「かつ」や「または」で組み合わせます。

* **`&&` (AND - かつ)**: 両方の条件が `true` のときだけ全体が `true` になります。
* **`||` (OR - または)**: どちらか一方でも `true` なら全体が `true` になります。
* **`!` (NOT - 否定)**: 真偽値を反転させます（`true` を `false` に、`false` を `true` に）。

```javascript
const hasTicket = true;
const isAdult = true;

if (hasTicket && isAdult) {
  console.log("入場できます。");
}

const isWeekend = true;
const isHoliday = false;

if (isWeekend || isHoliday) {
  console.log("今日はお休みです！");
}
```

---

## 4. Truthy（真っぽい値）と Falsy（偽っぽい値）

JSでは、Boolean型以外の値も、`if` 文の条件式に置かれると自動的に `true` または `false` のように扱われます。

### Falsy な値（これらはすべて `false` 扱いになります）
1. `false`
2. `0`（数値のゼロ）
3. `""`（空っぽの文字列）
4. `null`
5. `undefined`
6. `NaN` (Not a Number - 計算エラー値)

### Truthy な値
上記以外の値（例：数値の `1`、文字列の `"hello"`、空の配列 `[]` など）は、すべて `true` 扱いになります！

```javascript
const name = "アリス";

if (name) {
  // name は中身のある文字列（Truthy）なので、このブロックが実行されます！
  console.log(`こんにちは、${name}さん`);
}
```

## 5. ループ（繰り返し処理）

同じような処理を指定した回数だけ自動で繰り返したいときに使います。

### ① `for` ループ（回数を指定して繰り返す）
最もよく使われるループ文です。
`for (初期化; 条件式; 更新式)` の形で書きます。

```javascript
// i が 0 からスタートし、5未満の間、1ずつ増えながら繰り返す（計5回）
for (let i = 0; i < 5; i++) {
  console.log(`${i}回目のループです`);
}
```

### ② `while` ループ（条件が満たされている間繰り返す）
条件式が `true` である限り、ずっと処理を繰り返します。
無限ループ（ずっと終わりがないループ）にならないように、ループの中で条件が変わるようにする必要があります。

```javascript
let count = 0;

while (count < 3) {
  console.log(`カウント: ${count}`);
  count++; // これを忘れると無限ループになってブラウザがフリーズします！
}
```
