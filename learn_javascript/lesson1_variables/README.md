# 💡 Lesson 1: 変数・定数とデータ型

プログラミングの基本中の基本、**データを保存して再利用する仕組み（変数・定数）**と、**データの種類（データ型）**について学びます。

---

## 1. 変数と定数（値を記憶する箱）

JavaScriptでデータに名前をつけて保存するには、主に **`const`**（定数）と **`let`**（変数）を使います。

| 宣言方法 | 再代入（書き換え） | 主な用途 |
| :--- | :--- | :--- |
| **`const`** | **不可** ❌ | 基本はこれを使う！後から値を変えたくないデータ用。 |
| **`let`** | **可能** ⭕ | 後から中身を書き換える（更新する）可能性があるデータ用。 |

> 💡 **昔の書き方 `var` について**
> 昔のJavaScriptでは `var` が使われていましたが、現在ではバグの原因になりやすいため、特別な理由がない限り**使いません**。常に `const` を使い、必要に応じて `let` に切り替えるのがモダンなJSの鉄則です。

### 使い方：
```javascript
// const の例（定数：書き換え不可）
const taxRate = 0.1; 
// taxRate = 0.08; // ❌ エラーになります（TypeError: Assignment to constant variable.）

// let の例（変数：書き換え可能）
let score = 100;
score = 150; // ⭕ 別の値を上書きできます
```

## 2. データ型（データの種類）

JSで扱われる主なデータには、以下のような「型（タイプ）」があります。

### ① 文字列 (String)
文字を表現します。シングルクォーテーション `'`、ダブルクォーテーション `"`、またはバッククォーテーション `` ` `` で囲みます。
特にバッククォーテーションを使った**テンプレートリテラル**は非常に便利で、文字列の中に変数を埋め込むことができます。

```javascript
const name = "アリス";

// 従来の結合（+ を使う）
const greeting1 = "こんにちは、" + name + "さん！";

// テンプレートリテラル（${変数} を使う）
const greeting2 = `こんにちは、${name}さん！`; // バッククォーテーション「`」で囲みます
```

### ② 数値 (Number)
整数や小数を表します。四則演算（`+`, `-`, `*`, `/`）や、余りを求める（`%`）演算が可能です。

```javascript
const price = 1000;
const tax = price * 0.1; // 100
const total = price + tax; // 1100
```

### ③ 真偽値 (Boolean)
`true`（真）または `false`（偽）の2つの値しか持ちません。条件分岐などで使われます。

```javascript
const isLoggedIn = true;
const hasPermission = false;
```

### ④ 特別な値: `undefined` と `null`
* **`undefined`**: 変数を宣言したけれど、まだ何も値を入れていない（未定義）状態を表します。
* **`null`**: 開発者が意図的に「値が空っぽである」ことを示すために代入する値です。

```javascript
let address; // まだ値が入っていないので、中身は undefined
let cart = null; // カートが空であることを明示的に表す
```

---

## 3. 型を調べる方法：`typeof` 演算子

変数にどんなデータが入っているか分からないときは、`typeof` を使うとデータ型を文字列で教えてくれます。

```javascript
console.log(typeof "こんにちは"); // "string"
console.log(typeof 42);           // "number"
console.log(typeof true);         // "boolean"
```
