# 💡 Lesson 3: 関数（Functions）

同じ処理を何度も書くのを防ぎ、プログラムを整理整頓して再利用しやすくする強力な仕組み**「関数（かんすう）」**について学びます。

---

## 1. 関数とは？（処理をまとめる箱）

関数とは、**「入力（引数：ひきすう）」を受け取り、「特定の処理」をして、「出力（戻り値／返り値：もどりち）」を返す**ブラックボックスのようなものです。

```text
  [引数 (パラメータ)] ──> 【 ⚙️ 関数 (処理のまとまり) 】 ──> [戻り値 (結果)]
```

---

## 2. 関数の書き方（2つの主要なスタイル）

JavaScriptには関数の書き方がいくつかありますが、今日最も使われているのは以下の2つです。

### ① 従来の書き方（関数宣言：Function Declaration）
最も標準的な書き方です。 `function` キーワードを使用します。

```javascript
// 関数の定義（作る）
function greet(name) {
  return `こんにちは、${name}さん！`; // 戻り値を返す
}

// 関数の呼び出し（使う）
const message = greet("ボブ");
console.log(message); // "こんにちは、ボブさん！"
```

### ② モダンな書き方（アロー関数：Arrow Function）
ES6（2015年のアップデート）で登場した、より短く、スッキリと書けるモダンな書き方です。
実務のJSやReactなどのフレームワークでは、この書き方が主流になっています。

`function` という文字の代わりに、矢印 **`=>`**（アロー）を使います。

```javascript
// アロー関数の定義
const greetArrow = (name) => {
  return `こんにちは、${name}さん！`;
};

// 呼び出し方は同じ
console.log(greetArrow("アリス")); // "こんにちは、アリスさん！"
```

---

## 3. 引数（ひきすう）と 戻り値（もどりち）

### 引数（ひきすう）
関数を呼び出すときに、外から渡す「設定値」のことです。複数渡すこともできますし、何も渡さないこともできます。

```javascript
// 引数を2つ（a と b）受け取る関数
const add = (a, b) => {
  return a + b;
};

console.log(add(10, 20)); // 30
```

### 戻り値（もどりち：`return`）
関数が処理した結果を、呼び出し元に返す値のことです。
`return` が実行されると、**その時点で関数の処理は終了**し、呼び出し元に値が戻ります。

> ⚠️ **注意：`return` を書き忘れるとどうなる？**
> `return` がない関数は、処理結果として `undefined` を返してしまいます。値を返したいときは必ず `return` キーワードを書く必要があります。
>
> （ただし、アロー関数には「処理が1行だけの場合、`{}` と `return` を省略できる」という強力な省略ルールがあります。playground.jsで体験してみましょう！）

---

## 4. 変数のスコープ（有効範囲）

関数の中で宣言した変数や定数は、**その関数の「外側」からは使うことができません。**
これを「ローカルスコープ」と呼びます。

```javascript
const showLocal = () => {
  const secret = "秘密のメッセージ";
  console.log(secret); // ⭕ 関数の中なのでOK
};

showLocal();
// console.log(secret); // ❌ エラー！関数の外側からは secret は見えません（ReferenceError）
```

これにより、プログラム全体で同じ変数名が衝突するのを防ぎ、安全にコードを書くことができます。
